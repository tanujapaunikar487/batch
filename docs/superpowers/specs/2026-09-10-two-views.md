# Two views: Folders + Clear (v1.3)

One data model, two renderings of the same notes, switchable any time (⌘⇧V,
header button, ⋯ menu). Decided after four HTML prototypes and a live A/B
test-drive (docs/experiments/batch-test-drive.html): both "Shipped" (structured)
and "Clear" (calm) survived real use, so both ship — as views, not modes with
separate data.

## Unified semantics

Every note is in exactly one state, derived — nothing new is stored:

| State        | Derivation                       | Meaning                          |
| ------------ | -------------------------------- | -------------------------------- |
| `open`       | `!done && !handedOff`            | on your mind                     |
| `claude`     | `!done && handedOff`             | with Claude, waiting or answered |
| `done`       | `done`                           | handled                          |

- **Hand-off = Copy for agent.** Copying a note for the agent (⌥⌘C, folder
  ship, Clear's verbs) marks it `handedOff` — it does **not** mark it done any
  more (behavior change; `copyListMarksDone` now applies only to Copy as List).
- **Reopening clears the hand-off**: `setDone(ids, false)` also removes
  `handedOff`, so "bring it back / back to me" returns a note to `open`.
- Outcomes are unchanged: MCP `reply` or a pasted answer lands on the note and
  shows in both views; `mark_done` moves it to `done`.

## Folders view (default)

Today's UI, plus:

- Notes that are with Claude show a small **"with Claude"** chip until an
  outcome arrives.
- ⋯ menu wording: "Ship folder to Claude" (= copy the folder's **open** notes
  for the agent + mark them handed off).

## Clear view

Replaces the tabs + list area (search keeps the classic UI). Capture box stays
at the bottom (unchanged component, so ⇧⇧ / ⌥⇧S / drafts keep working; the
prototype's top placement lost to function). Cards show **all folders' notes**,
grouped by state — On your mind / With Claude / handled (collapsed) — with a
faint folder suffix when more than one folder is in use.

- Verbs: *Let Claude handle it* · *Done with it* · *clear* (delete). With
  Claude: *add the answer* (writes an outcome as "me") · *copy the block again*
  · *Done* · *back to me*. Handled: *bring it back*.
- *hand everything over to Claude* ships all open notes, block grouped by
  folder with each folder's agent instructions.
- Star = `priority: high`. No other priority UI; folders are not managed here.
- Status headline counts down: "N things on your mind · M with Claude", empty
  state "Nothing on your mind."
- Images/pins: same thumbnails + pin editor as the list view.
- Keyboard: capture box + global shortcuts work; list navigation (arrows into
  rows, Space, ⌘A) is Folders-view only for now.

## Settings

`viewMode: "folders" | "clear"` (default `folders`), persisted; new
customizable action `toggleView` (⌘⇧V).

## Addendum (2026-09-11): consistency pass

After native use: the two views must not diverge on structure or vocabulary.

- **Folders are shared.** The folder tabs render in both views; Clear shows the
  active folder's notes (headline, groups, hand-off all scoped to it). ⌘1-9,
  capture target, and Footer counts mean the same thing in both.
- **Priority collapsed to one ★ star, both views.** Starred = `priority: high`
  (schema unchanged, MCP still accepts high/medium/low; legacy "low" renders
  unstarred). Key `1` toggles it; the colored dot, 1/2/3 keys, and the priority
  dropdown are gone; the filter offers ★ Starred. Starred cards sort first in
  Clear.
- **Multi-select in Clear**: ⌘-click cards (same gesture as the list) → a
  floating bar with Hand to Claude / Done / Star / Merge / clear; Esc
  deselects. Selection state lives in App so the Esc cascade owns it.

Still Folders-view only, deliberately: section headings (Clear renders notes
flat), drag reorder, ⇧-click range select, arrow-key list navigation.

## Out of scope (deliberate)

Postage-stamp priority styling, batch numbers/sealing, per-view themes, Clear
list keyboard navigation, MCP marking `handedOff` on `list_notes`.
